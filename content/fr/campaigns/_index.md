title = "Financer une fonctionnalité"
description = "Campagnes de financement participatif à seuil pour des fonctionnalités open source précises de pgloader, pgcopydb et pg_auto_failover."
+++

Une fonctionnalité identifiée, un montant cible, un seuil de démarrage affiché.
En dessous du seuil, le développement ne commence pas. Au-dessus, le code est
écrit et publié sous licence libre, y compris pour ceux qui n'ont pas financé.
